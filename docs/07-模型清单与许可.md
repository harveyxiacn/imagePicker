# 07 模型清单与许可

> ⚠️ §1–§3 为**设计阶段的候选清单**，仓库名、文件、许可证以实现时 HuggingFace / 官方页面为准（模型生态更新很快）；**实际已落地的模型只有 §5 的表**（由注册表生成，28 项）。§2 中没有出现在 §5 的模型（SCRFD、MobileCLIP、DINOv2、TOPIQ/MUSIQ、Q-Align、DWPose、SAM 2、face-parsing、SegFormer、Depth Anything、FLUX、IC-Light、CodeFormer、Zero-DCE++、Florence-2、Qwen-VL 等）**均未采用**，保留仅供将来选型参考。
> 本项目代码开源；**模型权重不随仓库分发**，由用户在应用内按需下载，并在下载前展示许可证。
> 标注 **NC** 的模型为非商业许可（个人使用可以，商业使用需另行授权）——应用默认优先选用宽松许可模型，NC 模型标记为「可选」。

## 1. 下载源与机制

| 项 | 设计 |
|---|---|
| 下载源 | **现状**：HuggingFace 官方 → hf-mirror.com 镜像（用户在设置里选的源排最前）；MediaPipe 文件走 Google Storage 直连。ModelScope 在设置中可选，但注册表里还没有 ModelScope 条目，选它等同 `auto`（见 §5 末）；GitHub Release 未使用 |
| 自动选择 | `auto` = 官方失败再回落镜像；**没有**并行测速（计划项） |
| 可靠性 | 自研下载器（`models/download.py`）：HTTP Range 断点续传；SHA256 校验（registry 中记录）；下载到 `<models>/.partial/` 再原子移动 |
| 存储 | `<AppData>/imagePicker/models/`，可用设置 `models.dir` / `IMAGEPICKER_MODELS_DIR` 指到其他磁盘；复用已有 HF 缓存（`HF_HOME`）**未实现** |
| 格式 | 小模型优先 ONNX（fp16 版本按档位选择，**无 int8**）；MediaPipe / NIMA 用 `.task` / TFLite；重模型 safetensors（SDXL 修补，PyTorch） |
| 注册表 | `ai-worker/imagepicker_ai/models/registry.yaml` |

```yaml
# registry.yaml 示例
- id: siglip2-base
  task: [embed_image, embed_text, zero_shot]
  source: { hf: google/siglip2-base-patch16-224, modelscope: null }
  backend: onnx            # 由脚本导出并托管在本项目的 HF 组织下（含 fp16/int8）
  tiers: [T1, T2, T3]
  vram_mb: 450
  size_mb: 375
  license: Apache-2.0
  sha256: "…"
```

## 3. 各档位默认模型组合（现状，来自注册表 `tiers` 字段）

「默认」= 注册表里 `tiers` 含该档位的条目（`models.list` 的 `recommended`）。每档只列与上一档的差别；体积见 §5。

| 档位 | 默认模型 |
|---|---|
| T0 | YuNet、MediaPipe（人脸关键点 / 姿态 / 自拍多类分割）、AuraFace、NIMA（美学 + 技术质量）、skyseg-u2net、LaMa、SigLIP2-base（fp32 ONNX）、BiRefNet-lite-512、Real-ESRGAN x2 / x4（fp32）。助手无本地模型，使用离线规则引擎 |
| T1 | SigLIP2-base（fp32 与 fp16）+ 文本塔、BiRefNet-lite（fp32 与 fp16）、SCUNet 降噪、GFPGAN v1.4；助手规划模型 Qwen3-4B-Instruct（int4） |
| T2 | SigLIP2 fp16 + 文本塔、BiRefNet-fp16、Real-ESRGAN fp16 版、SCUNet、GFPGAN；助手规划模型 Phi-4-mini（int4，CUDA）、看图模型 Phi-3.5-vision（int4，CUDA；CPU 版仅 T2） |
| T3 | + SDXL Inpaint（可选增强包，PyTorch，需 `pro`/`torch` 相关 extras） |

`siglip2-base-torch` 的 `tiers` 为空：只作为没有 ONNX 导出时的回退，不是任何档位的默认。以上是**默认推荐**，不是能力门槛：核心功能在 CPU 上都能工作；只有助手的 LLM（T2+，或 T1 且有 GPU）/ VLM（T2+）在档位不足时被拒绝（`tier_too_low`，可用 `IMAGEPICKER_ASSISTANT_ANY_TIER=1` 覆盖）。

## 4. 许可合规策略

1. **代码**：本项目源码采用 Apache-2.0（见仓库 LICENSE）。
2. **权重**：不入库、不打包；应用内下载前显示模型许可摘要与原始链接，NC 模型需用户勾选"仅非商业用途"。
3. **默认集合只含宽松许可模型**（Apache/MIT/BSD/OpenRAIL），NC 模型以「增强包」形式可选。
4. **自训模型**（美学头、个性化头、3D LUT）使用宽松许可数据训练并以 Apache-2.0 发布到项目 HF 组织。
5. 发布前执行许可审计清单（`docs/` 中维护本表并在每个版本复核）。
