# imagePicker 设计文档总览

> 代号：**imagePicker**（产品名待定，候选：「拾光 PickLight」「一眼挑」）
> 定位：**本地优先、隐私安全、跨平台的 AI 照片挑选与修图工作台**。
> 场景：旅行、聚会、婚礼、活动、带娃……拍了几百上千张，回来后**几分钟内挑出好片、修好、导出**。

## 一页纸摘要

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 导入（秒开） → 智能分析（一键） → 分组筛选（键盘流） → 最佳表情 → 修图美化 → 导出 │
└───────────────────────────────────────────────────────────────────────────┘
```

1. **跨平台**：Tauri 2（Rust）桌面壳 + React Web 前端；同一套前端既是桌面 GUI，也可作为 **WebUI**（家里 4090 主机跑服务，笔记本/平板浏览器访问）。支持 Windows / CachyOS(Arch) / macOS，**Android 版**复用同一前端与 Rust 核心（Tauri 2 移动端），重计算可交给家中 GPU 主机。
2. **极速载入**：Rust 核心负责扫描、EXIF、缩略图（优先提取内嵌预览 + libjpeg-turbo DCT 缩放解码），虚拟化网格，万张级别流畅滚动。
3. **一键智能分析**：连拍/相似照片自动成组（时间 + 视觉嵌入），多维度评分映射到 0–5 星，问题标签（模糊、闭眼、过曝……）可解释。
4. **最佳表情（Best Take）**：同组连拍中每个人可选最佳表情，多候选横向对比，一键合成到底片。
5. **智能修图**：自动光影/色彩、人像美化（磨皮、美白、瘦脸、瘦手臂/腿等），全部**非破坏性**编辑栈。
6. **硬件自适应**：从纯 CPU 到 RTX 4090 分 4 档自动选择模型；高端卡可从 HuggingFace（支持镜像/ModelScope）下载 VLM、扩散模型做生成式修图与 AI 助手。
7. **额外亮点**：路人消除、人物识别与相册、自然语言搜索（"海边日落"）、个性化评分（学习你的口味）、多设备时间对齐、XMP 评分与 Lightroom/darktable 互通、自然语言 AI 助手。

## 术语表

| 术语 | 含义 |
|---|---|
| 连拍组 Burst | 秒级时间间隔内、画面高度相似的一组照片 |
| 场景 Scene | 分钟级、同一地点/主题的若干连拍组 |
| 事件 Event | 小时/天级的拍摄活动（如「Day2 京都」） |
| 精选 Pick / 淘汰 Reject | 筛选旗标，独立于星级 |
| AI 星级 / 用户星级 | AI 建议分与用户最终分分开存储，用户永远优先 |
| 编辑栈 Edit Stack | 非破坏性编辑操作的有序列表（JSON），原图永不修改 |
| 档位 Tier T0–T3 | 硬件能力分级，决定可用模型集合 |
| AI Worker | 独立的 Python 推理进程 |
