# 01 产品需求文档（PRD）

## 1. 产品愿景

> **"拍完不用愁，回来十分钟出片。"**

拍照越来越容易，挑照片越来越难。一次旅行 800 张、一次聚会 300 张，其中大量是连拍和相似构图；人一多，总有人闭眼、表情不自然。现有方案的问题：

| 现有方案 | 痛点 |
|---|---|
| 手机相册 / Google Photos | 需上传云端，隐私顾虑；挑片能力弱；不支持相机 RAW 工作流 |
| Lightroom / Capture One | 订阅制；AI 挑片能力有限；美颜需另开软件 |
| Photo Mechanic / FastRawViewer | 挑片快但无智能分析 |
| 美图秀秀 / 醒图 | 只能单张处理，无批量挑片，偏手机 |
| Aftershoot / Imagen 等 AI 挑片 | 面向专业摄影师、订阅、部分需联网 |

**imagePicker 的差异化**：本地运行 + 智能挑片 + 最佳表情合成 + 人像美化 + 批量统一风格，一站式，充分利用本地显卡，低端机器也能用。

## 2. 目标用户与场景

| 画像 | 描述 | 核心诉求 |
|---|---|---|
| P1 旅行爱好者 | 手机 + 微单，一次旅行数百到数千张 | 快速去重、挑每个景点最好的、统一色调、路人消除 |
| P2 聚会/家庭记录者 | 合照多、人多、带娃 | 合照每人都睁眼笑、自动挑出每个人好看的、美颜 |
| P3 业余摄影师 | RAW 拍摄、婚礼/活动跟拍 | 高速挑片、评分与 Lightroom 互通、批量修图 |
| P4 家庭服务器用户 | 有一台带显卡的主机（如 CachyOS + 4090） | 在主机上跑服务，任何设备浏览器访问 |

### 典型用户故事

- **US-01**：作为旅行者，我把 SD 卡里 1200 张照片拖进来，**10 秒内**看到全部缩略图，点「一键分析」，喝杯咖啡回来，照片已按场景分组、每组最佳一张置顶并有星级。
- **US-02**：作为聚会组织者，我打开一组 8 张连拍合照，看到「人物 × 帧」表情矩阵，为每个人点选最好的表情，生成一张所有人都睁眼微笑的合照。
- **US-03**：我只想要 4 星以上且无人闭眼的照片，一个筛选条件即可，然后批量导出到「精选」文件夹。
- **US-04**：我选中一个人，开启「自然美颜」，磨皮、美白、瘦脸只作用于这个人，不影响旁边的小朋友。
- **US-05**：我对 AI 助手说「把这次京都的照片统一成胶片风，偏暖」，它批量应用并让我逐张微调。
- **US-06**：我把几张评分改了，系统学习后对剩下的照片重新排序，越来越懂我的口味。
- **US-07**：朋友用 iPhone、我用索尼拍了同一场聚会，系统自动校正两台设备的时间差后合并时间线。

## 3. 功能需求

优先级：**P0** = MVP 必须；**P1** = 1.0 正式版；**P2** = 后续版本。

### F1 素材导入与浏览

| ID | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1.1 | 文件夹/拖拽导入 | 递归扫描，支持排除规则；不复制原图（引用模式） | P0 |
| F1.2 | 格式支持 | JPEG、PNG、WebP、HEIC/HEIF、AVIF、TIFF；RAW（CR2/CR3/NEF/ARW/RAF/ORF/RW2/DNG）；RAW+JPEG 自动配对 | P0（RAW 预览）/ P1（RAW 全解码） |
| F1.3 | 极速缩略图 | 渐进式：内嵌缩略图 → 网格缩略图 → 预览图 → 原图；可视区域优先 | P0 |
| F1.4 | 虚拟化网格 | 1 万张以上流畅滚动；缩略图尺寸可调 | P0 |
| F1.5 | 大图查看 Loupe | 适应/100%/任意缩放，平移；RAW 显示内嵌预览，可切换全解码 | P0 |
| F1.6 | 对比视图 | 2/3/4-up 同步缩放与平移；N-up 组对比 | P0 |
| F1.7 | 文件监听 | 文件夹新增/删除/移动自动同步 | P1 |

|---|---|---|---|
| F2.1 | 一键分析 | 选择档位（快速/标准/深度）；后台任务，可暂停/继续；增量分析 | P0 |
| F2.2 | 连拍/相似分组 | 时间间隔 + 视觉嵌入相似度；三级层次：连拍组 → 场景 → 事件 | P0 |
| F2.3 | 组内排序与最佳推荐 | 每组自动推荐 Top1，组折叠为堆栈（Stack）显示 | P0 |
| F2.4 | 质量评分 | 技术质量（清晰度/曝光/噪点）、美学、人脸（睁眼/笑容/视线）、构图、冗余惩罚 → 0–100 分 → 0–5 星 | P0 |
| F2.5 | 问题标签 | 模糊、跑焦、闭眼、过曝/欠曝、倾斜、遮挡、表情不佳、手指/路人入镜 | P0 |
| F2.6 | 可解释性 | 每张照片显示评分分解与原因（"主体人物左眼闭合 -1.2 星"） | P0 |
| F2.7 | 人物识别与聚类 | 人脸检测、特征提取、跨照片聚类为「人物」，可命名、合并、拆分 | P1 |
| F2.8 | 场景识别 | 人像/风景/美食/建筑/夜景/宠物等，影响评分权重 | P1 |
| F2.9 | 自然语言搜索 | "海边日落"、"穿红衣服的小孩"（图文嵌入） | P1 |

| F2.11 | 多设备时间对齐 | 不同设备时间偏移自动估计（基于相似画面）+ 手动校正 | P1 |
| F2.12 | 重复检测 | 跨文件夹完全重复/近似重复检测 | P1 |

| ID | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F3.1 | 星级 0–5 | 键盘 0–5 直接打分；AI 星级与用户星级分开存储 | P0 |

### F4 最佳表情（Best Take）

| ID | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F4.1 | 人物×帧表情矩阵 | 连拍组中每个人在每一帧的人脸裁切，标注睁眼/笑容/视线分数 | P0 |
| F4.2 | 每人推荐 Top-K 表情 | 默认推荐 3 个候选，可展开全部 | P1 |
| F4.3 | 换脸合成 | 以底片为基础，将选中帧的该人物脸部区域对齐、融合到底片 | P1 |
| F4.4 | 一键全员最佳 | 自动选底片 + 每人最佳表情 → 生成合成图（作为新的虚拟副本） | P1 |

> 约束：仅在**同一连拍组、同一人物**之间替换（Best Take 语义），不提供跨人物换脸。

## 4. 非功能需求

| 类别 | 指标（参考机器：16 核 CPU + NVMe + RTX 4090） | 低端基线（8 核 / 16GB / 无独显） |
|---|---|---|
| 启动 | 冷启动 < 2s 到可交互 | < 4s |
| 首屏 | 导入 1000 张 JPEG，首屏缩略图 < 1s，全部网格缩略图 < 10s | < 30s |
| RAW | 1000 张 RAW（提取内嵌预览）< 15s | < 40s |
| 浏览 | 网格滚动 60fps；Loupe 切换下一张 < 50ms（已预读） | < 120ms |
| 分析 | 标准分析 1000 张 < 2 分钟 | 快速分析 1000 张 < 10 分钟 |
| 修图 | 滑块调整预览延迟 < 50ms（预览分辨率） | < 150ms |
| 规模 | 单库 10 万张；单次会话 2 万张 | 单次会话 5000 张 |
| 内存 | 常驻 < 1.5GB（不含模型） | — |
| 可靠性 | 原图只读；崩溃不丢评分（WAL 实时落库）；分析任务可断点续跑 | 同 |
| 隐私 | 默认零网络请求；局域网模式需鉴权 | 同 |
| 可访问性 | 全键盘操作；高对比度；字体缩放 | 同 |

## 5. 范围之外（v1.0 不做）

- 视频剪辑（仅考虑 Live Photo / 动态照片抽帧，P2）
- 云同步、多人协作
- 跨人物换脸、任何"深度伪造"类功能
- iOS 版（Android 版见 [08 Android 版本设计](08-Android版本设计.md)，在 1.0 之后交付）

## 6. 成功指标

| 指标 | 目标 |
|---|---|
| AI Top-1 命中率：用户最终选择的照片在 AI 组内 Top-1 | ≥ 60% |
| AI Top-3 命中率 | ≥ 85% |
| 闭眼检测召回率 | ≥ 95%（误报 ≤ 5%） |
| 连拍分组 F1 | ≥ 0.9 |
| 挑片耗时 | 相比纯手动减少 ≥ 60%（自测 1000 张场景） |
| 星级一致性：AI 星级与用户星级差 ≤ 1 的比例 | ≥ 75%（个性化后 ≥ 85%） |
