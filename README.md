# imagePicker

> 本地优先、隐私安全、跨平台的 AI 照片挑选与修图工作台。
> A local-first, cross-platform AI photo culling & retouching workstation.

旅行、聚会拍了上千张？拖进来，一键分析：连拍与相似照片自动成组、0–5 星智能评分、闭眼/模糊自动标记、合影「全员最佳表情」合成、自动光影色彩与人像美化——全部在本地完成。

**状态**：🚧 设计阶段（v0.1 设计文档已完成，进入 M0 技术验证）

## 特性规划

- ⚡ **极速载入**：Rust 原生缩略图流水线（内嵌预览提取 + DCT 缩放解码），万张级流畅浏览
- 🧠 **一键智能分析**：连拍/场景/事件三级分组、可解释的多维评分、人物识别
- 😀 **最佳表情**：人物×帧表情矩阵，每人选最佳表情合成
- 🎨 **智能修图**：自动光影色彩、智能蒙版、预设/LUT、批量统一风格
- 💄 **人像美化**：磨皮、美白、瘦脸、瘦手臂/腿，按人物单独设置，自然度保护
- 🧽 **生成式修复**：路人消除、降噪、超分、人脸修复
- 🤖 **AI 助手**：自然语言筛选与批量操作
- 🖥️ **跨平台**：Windows / Linux（CachyOS）/ macOS 桌面 + WebUI（局域网访问）+ Android
- 🎛️ **硬件自适应**：纯 CPU 到 RTX 4090 四档模型；模型可从 HuggingFace / 镜像 / ModelScope 按需下载
