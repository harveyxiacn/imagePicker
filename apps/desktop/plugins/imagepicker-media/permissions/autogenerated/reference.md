## Default Permission

All imagepicker-media commands (Android only; the plugin is not registered on desktop).

#### This default permission set includes the following:

- `allow-request-permission`
- `allow-list-albums`
- `allow-share`
- `allow-trash`
- `allow-start-foreground`
- `allow-stop-foreground`
- `allow-keep-awake`
- `allow-publish-exports`
